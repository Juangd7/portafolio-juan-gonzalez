Política de privacidad

Última actualización: 2025

1. Quién es el responsable

Juan Esteban González Díaz, diseñador visual independiente. Para contactar por temas relacionados con privacidad, usa el formulario de contacto disponible en este sitio.

2. Qué datos se recopilan

Este sitio web recopila únicamente los datos que tú proporcionas de forma voluntaria a través del formulario de contacto:

  • Nombre
  • Dirección de correo electrónico
  • Información sobre tu proyecto o marca
  • Presupuesto estimado y fecha tentativa

No se instalan cookies de seguimiento, ni se utiliza Google Analytics ni ningún otro sistema de analíticas de terceros.

3. Para qué se usan tus datos

Los datos recopilados a través del formulario de contacto se utilizan exclusivamente para responder a tu consulta y, en caso de que se establezca una relación profesional, para gestionar el proyecto.

4. Con quién se comparten

Los datos del formulario son procesados por Netlify (netlify.com), el proveedor de hosting de este sitio, mediante su servicio de formularios. Netlify actúa como encargado del tratamiento. Para más información consulta la política de privacidad de Netlify.

No se venden ni comparten datos con terceros con fines publicitarios o comerciales.

5. Durante cuánto tiempo se conservan

Los datos se conservan durante el tiempo necesario para gestionar la consulta o el proyecto. Puedes solicitar la eliminación en cualquier momento.

6. Tus derechos

Tienes derecho a acceder, rectificar, suprimir, limitar el tratamiento, y oponerte al uso de tus datos. Para ejercer cualquiera de estos derechos, contacta a través del formulario de contacto del sitio.

7. Cambios en esta política

Esta política puede actualizarse. La fecha de la última modificación aparece en la cabecera de este documento.
